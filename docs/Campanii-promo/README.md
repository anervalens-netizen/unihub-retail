# Campanii promo — documente private

Acest director nu stochează anexe, regulamente sau rapoarte comerciale.

- Documentele sursă se păstrează în storage operațional privat, în afara Git.
- Runtime-ul folosește generațiile promo imuabile și neversionate din
  `data/promo_generations/`, incluse în backupul operațional.
- În Git pot exista doar documentație tehnică, identificatori și hashuri fără
  conținut comercial sau date personale.
- Fișierele PDF, Office și prezentările sunt blocate prin `.gitignore` și prin
  testul de repository hygiene.
